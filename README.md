# 电容式传感器 · 3D 交互课件

纯静态页面，无需后端。部署到任意静态托管即可通过网址访问。

## 本地预览
双击 `index.html`，或用任意静态服务器：
```
python -m http.server 8000
```

## 网址参数
- `?fast=1`  关闭阴影/后处理，手机与低端机推荐
- `?p=mic|rpm|level|rot`  直接进入某个模块
- `?d0=...&n=...&z=...&h=...&er=...&a=...&b=...&d=...`  预设参数

## 键盘
`1`–`4` 切换模块，空格暂停，双击复位。

## 说明
- 所有贴图与模型已内联，页面不依赖外部 CDN
- 振膜振幅、齿盘转速等为教学示意，数值已按公式实时计算
